# 스토어 등록 정보 초안 (구글 플레이, 한국어)

글자 수 제한(2026년 기준, 출시 직전에 콘솔에서 다시 확인): 앱 이름 30자, 짧은 설명 80자, 긴 설명 4,000자.

## 앱 이름 (30자 이내)

- 후보 1: `그림 그리기 - 50가지 도구`
- 후보 2: `그림 그리기`

같은 이름의 앱이 이미 있을 수 있으니 콘솔에서 이름을 입력할 때 확인한다. 상표나 유명 캐릭터 이름은 넣지 않는다.

## 짧은 설명 (80자 이내)

- 후보 1: `50가지 도구로 그리는 그림 앱. 그림은 내 기기에만 저장돼요.`
- 후보 2: `펜·붓·도형·레이어까지, 인터넷 없이도 그리는 무료 그림 앱`

## 긴 설명 (4,000자 이내)

```
그림 그리기는 50가지 도구로 마음껏 그리는 무료 그림 앱입니다.

■ 이런 것을 할 수 있어요
• 펜·연필·붓·크레용·목탄 등 50가지 도구
• 원하는 색(색 코드 입력 가능)과 두께 선택, 최근 사용한 색
• A4, B2 등 A0~A6·B0~B6 용지 크기 선택
• 레이어(최대 30장까지, 용지 크기에 따라 적어짐): 보이기·숨기기, 불투명도, 잠금, 순서 바꾸기
• 사각·올가미·마술봉 선택, 복사·붙여넣기, 크기·회전·뒤집기
• 도형, 채우기, 그라데이션, 패턴, 스티커, 글자 넣기, 대칭 그리기
• 되돌리기·다시하기(최근 100단계)
• 사진을 불러와 배경이나 새 레이어로 쓰기
• PNG·JPG·PDF로 내보내기, 투명 배경 PNG
• 라이트·다크 화면

■ 마우스, 손가락, 펜 모두 OK
컴퓨터에서는 마우스로, 폰과 태블릿에서는 손가락이나 펜으로 그릴 수 있어요. 펜 압력에 따라 굵기가 변하는 도구도 있어요.

■ 그림이 사라지지 않아요
그리는 대로 자동 저장돼요. 앱을 닫거나 새로고침해도 그리던 그대로 이어서 그릴 수 있고, 백업 파일로 보관하거나 다른 기기로 옮길 수 있어요.

■ 인터넷이 없어도 그려요
한 번 설치하면 비행기 모드에서도 그릴 수 있어요.

■ 내 그림은 내 기기에만
그림은 서버로 보내지 않고 이 기기에만 저장돼요. 로그인도, 광고도 없어요.

무료 앱입니다. 문의: [이메일]
```

> 이 출시는 AI를 뺀 버전이라 AI 이야기는 넣지 않는다. 설명에 적은 기능은 **실제 앱에 있는 것만** 적는다(과장하면 심사에서 문제가 된다).

## 스크린샷으로 만들 화면 (폰용 최소 2장, 권장 6~8장)

플레이 기준: JPEG 또는 24비트 PNG, 각 변 320~3,840px, 긴 변이 짧은 변의 2배 이하(세로 9:16 권장). 실제 앱 화면을 찍는다.

| # | 화면 | 보여 줄 것 |
| --- | --- | --- |
| 1 | 그리는 중 | 색과 두께를 고른 채 그린 그림 한 장(대표 화면) |
| 2 | 도구 목록 | 도구 패널(펜·붓·도형 탭) |
| 3 | 레이어 | 레이어 3장, 불투명도·잠금이 보이는 화면 |
| 4 | 새 그림 | 용지 크기 선택(A4/B2 등) |
| 5 | 내 그림 목록 | 그림 여러 개가 있는 홈 |
| 6 | 다크 모드 | 어두운 화면으로 그린 그림 |
| 7 | 내보내기·백업 | 파일 패널(PNG/JPG/PDF)과 백업 |

## 그래픽 자료

- 앱 아이콘: 512×512 PNG(`public/icons/icon-512.png` 사용 가능, 1MB 이하).
- 대표 이미지(피처 그래픽): 1024×500 PNG/JPEG. 아직 없음 → 아이콘과 그림 예시 화면으로 만든다.
- 태블릿 스크린샷은 선택이지만 있으면 태블릿 노출에 유리하다.

## 분류

- 카테고리: 그림 그리기가 없으면 "예술 및 디자인" 또는 "도구".
- 연락처: 이메일(필수), 웹사이트(선택), 개인정보처리방침 URL(필수).
