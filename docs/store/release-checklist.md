## G. 콘텐츠 등급(연령 등급) 설문 — 답변 초안

콘솔의 질문 문구는 바뀔 수 있으니 문구를 읽고 그 뜻에 맞게 답한다. 앱 종류는 "유틸리티/제작 도구" 계열(게임 아님)을 고른다.

| 질문 | 초안 답 | 이유 |
| --- | --- | --- |
| 폭력(만화·사실적 폭력, 피, 잔혹) | 아니요 | 그림을 그리는 도구일 뿐 폭력 콘텐츠를 제공하지 않음 |
| 성적인 콘텐츠·노출 | 아니요 | 제공하는 콘텐츠 없음 |
| 욕설·거친 언어 | 아니요 | 앱이 제공하는 글에 없음 |
| 마약·술·담배 | 아니요 | 없음 |
| 도박(실제·시뮬레이션) | 아니요 | 없음 |
| 사용자 간 상호작용·사용자 생성 콘텐츠 공유 | **아니요** | 로그인·공유·채팅이 없음. 그림은 사용자 기기에만 있음 |
| 위치 공유 | 아니요 | 위치를 쓰지 않음 |
| 개인 정보 공유·수집 | 아니요 | 방침과 데이터 보안 양식과 **같은 답**이어야 함 |
| 디지털 구매 | 아니요 | 무료, 결제 없음 |
| 생성형 AI 기능 | 아니요 | 이 출시에는 AI가 없음 |

설문 결과의 등급은 나온 그대로 받아들이고 임의로 낮추지 않는다. 그림을 그리는 사용자는 무엇이든 그릴 수 있지만 그 그림은 공유되지 않으므로 "사용자 생성 콘텐츠"가 아니라고 본다. 나중에 공유 기능을 넣으면 다시 답해야 한다.

## H. 대상 연령 (AI를 뺀 모든 연령용)

- 이 앱은 모든 연령이 쓸 수 있지만, **13세 미만 어린이를 대상 연령에 포함하면 플레이의 "가족 정책"과 어린이 관련 규정이 추가로 적용**된다(광고·분석 도구 제한, 앱 내용 기준 등). 이 앱은 광고·분석·계정·외부 전송이 없어 조건을 맞추기 쉽지만, 콘솔의 정책 안내를 출시 직전에 정확히 읽고 답한다.
- 초안 권장: 대상 연령대를 고를 때 **어린이가 포함되는지**를 콘솔 질문 그대로 신중히 정한다. 어린이를 포함하면 가족 정책 확인 항목을 하나씩 통과해야 하고, 포함하지 않으면 "일반 사용자 대상(아동 전용 아님)"으로 답한다. 이 결정은 부모님과 함께 한다.
- AI가 없으므로 "18세 이상만" 조건은 필요 없다.
