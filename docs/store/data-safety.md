# 개인정보처리방침 링크와 플레이 콘솔 "데이터 보안" 답변 초안 (AI를 뺀 출시)

> 초안이며 법률 자문이 아니다. 구글 플레이 정책과 양식은 바뀔 수 있으므로 **출시 직전에 플레이 콘솔의 안내와 도움말을 다시 읽고**, 질문 문구가 다르면 그 문구에 맞게 답한다. 질문을 잘못 답하면 심사에서 거절될 수 있다.

## 개인정보처리방침

- 초안 파일: `public/privacy.html` (앱을 올리면 `https://내주소/privacy.html`로 열린다. 앱 안 "설정 → 개인정보처리방침"에서도 열린다.)
- 채울 곳: 시행일, 운영자 이름, 문의 이메일. (`node scripts/check-release.mjs`가 남은 빈칸을 알려 준다.)
- 플레이 콘솔 "앱 콘텐츠 → 개인정보처리방침"에 위 주소를 넣는다.
- 주소는 로그인 없이 누구나 열려야 하고, PDF가 아니라 웹 페이지여야 한다.

## 데이터 보안 양식 — 답변 목록

앱의 실제 동작(코드 기준): 그림·설정은 기기에만 저장되고 개발자 서버는 없다. 이 출시 빌드에는 AI 기능(제미나이 코드)이 들어 있지 않아 그림·입력을 인터넷으로 보내는 기능이 없다. 광고·분석·로그인·결제·위치·연락처·카메라·마이크도 없다. 앱 파일을 내려받는 웹 서버(호스팅)의 접속 기록은 호스팅 업체가 남길 수 있다(방침 3장에 적어 둠).

| 질문 | 답 |
| --- | --- |
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** (수집·공유 없음) |
| 데이터는 전송 중 암호화되나요? | 해당 없음(데이터를 보내지 않음). 양식이 요구하면 "예"(앱 파일은 HTTPS로 내려받음) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | 해당 없음(개발자가 보관하는 데이터 없음. 앱을 지우면 기기 데이터도 삭제됨) |
| 개인정보처리방침 URL | `https://내주소/privacy.html` |

### 앱 콘텐츠의 다른 양식

- **광고**: 광고 없음.
- **정부 앱, 금융·건강 기능, 뉴스 앱**: 아니요.
- **생성형 AI 기능**: 이 빌드에는 없다(콘솔에서 AI 관련 질문이 나오면 "없음").
- **타깃층·콘텐츠**: `release-checklist.md`의 H(대상 연령)를 본다.

## 앱이 요구하는 안드로이드 권한

TWA 기본값은 인터넷 접근뿐이며 알림(`enableNotifications`)은 꺼 두었다. 카메라·위치·저장소 권한은 요구하지 않는다. `bubblewrap build` 뒤 `AndroidManifest.xml`에 예상 밖의 권한이 없는지 확인한다.

## 나중에 AI를 넣게 되면

`npm run build:with-ai`로 만들 수 있지만, 그때는 다음이 모두 바뀐다: 구글 API는 만 18세 이상만 쓸 수 있으므로 대상 연령을 18세 이상으로 올려야 하고, 방침에 "AI를 쓸 때 입력한 글·그림 이미지·API 키가 구글로 전송된다"를 넣어야 하며, 이 표의 답(사용자 데이터를 제3자에게 공유, 사진·사용자 생성 콘텐츠, 앱 기능 목적, 선택 사항)과 콘텐츠 등급 설문, AI 생성 콘텐츠 정책도 다시 답해야 한다. 그 전에는 넣지 않는다.
